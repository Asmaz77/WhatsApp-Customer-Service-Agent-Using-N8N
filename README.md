📋 نظرة عامة على المشروع (Overview)
هذا المشروع عبارة عن مساعد ذكي لخدمة العملاء والمبيعات عبر واتساب. يعتمد على n8n لإدارة سير العمل، وGoogle Gemini كوكيل ذكي يفهم استفسارات العملاء، مع ربطه بـ Google Sheets كقاعدة معرفة داخلية تحتوي على تفاصيل المنتجات وسياسات المتجر لضمان ردود دقيقة وموثوقة دون أي تخمين.

🛠️ المتطلبات السابقة (Prerequisites)
برنامج Docker (لتشغيل Open-WA).

حساب n8n فعال (سواء على السحابة الرسمية أو محلياً).

حساب Google Cloud / Google Drive لربط ملفات البيانات.

⚙️ خطوة التشغيل والإعداد (Installation Steps)
1. استيراد ملف الـ Workflow
قم بتحميل ملف الـ JSON الخاص بالـ Workflow من هذا المستودع (workflow.json).

افتح منصة n8n، أنشئ Workflow جديد، ثم قم باستيراد (Import) الملف بداخلها.

2. تشغيل وإعداد Open-WA API عبر Docker
قم بتثبيت وتشغيل حاوية Open-WA باستخدام التعليمات الموجودة في موقعهم الرسمي عبر Docker.

بعد التشغيل، ستجد الـ API Key الخاص بالبرنامج داخل مجلد البيانات الخاص بالحاوية (غالباً في المسار OpenWA/data). احتفظ به لاستخدامه لاحقاً.

افتح واجهة Open-WA، أنشئ جلسة جديدة (New Session)، وقم بربط رقم الواتساب الخاص بك عن طريق مسح رمز الاستجابة السريعة (QR Code).

3. ربط وتكوين عقد الـ n8n
قم بضبط العقد الأساسية داخل الـ Workflow كالتالي:

عقدة Google Gemini Chat Model: افتح العقدة وأضف بيانات الاعتماد الخاصة بك (API Key الخاص بـ Gemini).

عقدة Simple Memory: مخصصة للاحتفاظ بسياق المحادثة؛ الافتراضي مضبوط على الاحتفاظ بآخر 20 رسالة (يمكنك تعديلها حسب رغبتك).

عقدة Google Sheets (قاعدة المعرفة): قم برفع ملفات البيانات الخاصة بمتجرك على Google Drive، اربط بيانات الاعتماد الخاصة بحساب خدمة جوجل (Google Service Account)، وتأكد من منح صلاحية الوصول للملفات المطلوبة.

عقدة AI Agent (الوكيل الذكي): قم بتحديث وتخصيص الـ System Prompt ليعكس هوية وطبيعة متجرك.

4. إعداد الاتصال بين n8n و Open-WA (الـ Webhook)
من عقدة Webhook في n8n، انسخ رابط الـ Webhook الخاص بالاختبار (Test URL).

توجه إلى لوحة تحكم Open-WA، وأضف Webhook جديد وضع الرابط الذي نسخته لتستقبل الرسائل.

5. إعداد عقدة الـ HTTP Request (لإرسال الردود)
في عقدة HTTP Request المخصصة لإرسال الرد للعميل، قم بتعديل البيانات التالية:

رابط الـ URL: اجعله بالشكل التالي، مع استبدال الرابط ومعرف الجلسة بمعلوماتك:
https://YOUR_TUNNEL_URL/api/sessions/YOUR_SESSION_ID/messages/send-text

مفتاح المصادقة (X-API-Key): ضع الـ API Key الخاص بـ Open-WA الذي استخرجته من مسار البيانات (OpenWA/data) سابقاً.

مُعرف الدردشة والرسالة: تأكد من مطابقة حقول chatId و text لتضمن إرسال الرد للعميل بالشكل الصحيح.

🚀 تشغيل الاختبار والانطلاق (Testing & Production)
قم بتشغيل واختبار الـ Workflow بشكل كامل عبر إرسال رسالة تجريبية لرقم الواتساب المتصل والتأكد من استقبال الردود بنجاح.

عند التأكد من عمل النظام بنجاح: قم بتغيير رابط الـ Webhook في n8n من وضع Test إلى وضع Production، ونسخه، ثم تحديثه داخل إعدادات Open-WA.

💡 ملاحظات هامة جداً للتشغيل المحلي (Localhost):

إذا كان برنامج n8n يعمل محلياً على جهازك (Local Server)، فلن يتمكن واتساب من إرسال البيانات إليه مباشرة لأنه غير مرئي على شبكة الإنترنت.

لحل هذه المشكلة، يجب عليك فتح بورت عام باستخدام أداة مثل Ngrok أو Cloudflare Tunnels.

استبدل رابط الـ http://localhost:5678 بالرابط العام (Public Tunnel URL) الناتج من Ngrok أو Cloudflare ليصبح قادراً على استقبال الردود والرسائل من واتساب بنجاح.
